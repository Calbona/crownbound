# 核心规则

> 版本：v1.0
>
> 整理日期：2026-11-6
>
> 本文档负责：游戏核心玩法继承人棋的规则

---

## 1 总则

继承人棋（Crownbound）是一种双人回合制棋类游戏。左方为先手，右方为后手。双方棋子种类与数量相同。游戏以到达目标点为核心胜负机制。

简单来说，本棋的创新点在于：
- 核心目标不是一定要把对方的“王”吃掉，而是让己方的“王”比对方的更快抵达一个目标点。
- 棋盘形状不是规则的矩形，双方棋手也不是面对面，而是左右并立，沿中轴对称。
- 棋子之间不是任意吃子的关系，而是有专门的“天敌”。
- 借鉴了多种经典棋类游戏，比如中国象棋、跳棋。

## 2 棋盘

### 2.1 坐标系

- 棋盘使用整数坐标 `(c, r)` 表示结点。

- 列 `c` 的范围：`0 ~ 6`。

- 行 `r` 的范围：`0 ~ 6`。

- 左下角结点为 `(0, 0)`。

### 2.2 存在的结点

并非所有 `(c, r)` 处都存在结点。存在的结点集合为：

- 行 `0, 1`：列 `0, 1, 2, 4, 5, 6`。

- 行 `2 ~ 4`：列 `0 ~ 6`。

- 行 `5, 6`：列 `2, 3, 4`。

```
6  ·  ·  ○  ○  ○  ·  ·    ○ 存在的结点
5  ·  ·  ○  ○  ○  ·  ·    · 不存在的结点
4  ○  ○  ○  ○  ○  ○  ○
3  ○  ○  ○  ○  ○  ○  ○
2  ○  ○  ○  ○  ○  ○  ○
1  ○  ○  ○  ·  ○  ○  ○
0  ○  ○  ○  ·  ○  ○  ○
   0  1  2  3  4  5  6
```

### 2.3 目标点

目标点为 `(3, 6)`，位于棋盘最顶部正中间。

### 2.4 实线

若两个结点在水平或垂直方向上相邻，则它们之间有一条实线连接。

### 2.5 虚线

棋盘上共有 6 条虚线，它们形成的图形关于棋盘中轴对称：

- `(0, 0) — (2, 1)`
- `(2, 0) — (1, 1)`
- `(2, 2) — (4, 3)`
- `(6, 0) — (4, 1)`
- `(4, 0) — (5, 1)`
- `(4, 2) — (2, 3)`

从虚线一端的结点到另一端的结点，棋子可以移动一步，不能吃子，且那一端的结点必须为空。

## 3 棋子

### 3.1 棋子的种类、数量和初始布局

| 种类 | 数量 | （左方）初始位置 |
|---|---:|:---|
| 推进子 | 1 | `(1, 0)` |
| 翻越子 | 2 | `(0, 0)`，`(2, 0)` |
| 阻碍子 | 2 | `(0, 1)`，`(2, 1)` |
| 威胁子 | 1 | `(1, 2)` |

可以看出，左方的棋子初始布局是关于左方中轴（`c = 1`）对称的。

右方的棋子初始布局由左方关于棋盘中轴对称得到。

### 3.2 走法

每次走子选择其中一种移动方式：

- **推进子**

    1. 若实线相邻结点为空，则占据；若该结点上有对方翻越子或威胁子，则吃子并占据。
    1. 若虚线相邻结点为空，则占据。
    1. 若与翻越子（己方或对方均可）实线相邻，且翻越子背后结点存在且为空，则占据该结点。然后可以重复此判定，连续翻越多个翻越子，整个翻越过程只算作一次移动，但结束过程时不能回到翻越前的初始位置。翻跃走法不能吃子。

    *注意：如果目标点上有对方任意棋子，推进子也将其视为空结点，此规则称为 **达标无阻规则**。*

    *推进子移动之后占据 (c', r')，记作：`adv -> c', r'`。*

- **翻越子**

    1. 从 `(c, r)` 移动到 `(c ± 1, r ± 2)` 或 `(c ± 2, r ± 1)`，走法类似中国象棋的马。若该结点为空，则占据；若该结点上有对方翻越子或威胁子，则吃子并占据。受蹩马腿规则限制：到 `(c ± 1, r ± 2)`，马腿结点为 `(c, r ± 1)`；到 `(c ± 2, r ± 1)`，马腿结点为 `(c ± 1, r)`。当马腿结点不存在或被占据时，该马步不能走。
    1. 若虚线相邻结点为空，则占据。

    *翻越子移动之后占据 (c', r')，记作：`vau c, r -> c', r'`。*

- **阻碍子**

    1. 若实线相邻结点为空，则占据。
    1. 若虚线相邻结点为空，则占据。

    *阻碍子移动之后占据 (c', r')，记作：`blo c, r -> c', r'`。*

- **威胁子**

    1. 从 `(c, r)` 移动到 `(c + i, r)` 或 `(c, r + j)`（`i, j` 为任意非零整数），路径上所有结点必须存在且为空，走法类似中国象棋的车。若该结点为空，则占据；若该结点上有对方推进子，则吃子并占据。
    1. 若虚线相邻结点为空，则占据。

    *注意：威胁子不能进入禁区，即 `r ≥ 5` 的结点，所以不能吃禁区内的推进子，此规则称为 **威胁子高度限制**。*

    *威胁子移动之后占据 (c', r')，记作：`thr -> c', r'`。*

### 3.3 吃子关系

己方棋子只能吃对方的棋子。

| 棋子 | 可以吃哪些棋子 | 可以被哪些棋子吃 |
|---|---|---|
| 推进子 | 翻越子，威胁子 | 威胁子 |
| 翻越子 | 翻越子，威胁子 | 推进子，翻越子 |
| 阻碍子 | - | - |
| 威胁子 | 推进子 | 推进子，翻越子 |

## 4 回合流程

1. 左方先手。
1. 双方轮流行棋。
1. 若胜利条件达成，游戏结束。
1. 否则进行下一回合。

---

## 5 胜负判定

### 5.1 胜

#### 5.1.1 吃掉对方推进子

只要吃掉对方推进子，己方立即获胜。

#### 5.1.2 推进子达标

情况一：左方推进子达标

1. 检查右方推进子是否能在当前局面下，一步合规移动达标。
1. 若存在这样的合规一步，则右方获胜。
1. 若不存在这样的合规一步，则左方获胜。

*此规则称为 **后手平衡规则**。*

情况二：右方推进子达标

右方立即获胜。

### 5.2 和

以下情况和棋：

- **一方无合规走法**：若轮到一方行棋时，没有任何合规走法，和棋。
- **重复局面**：同一局面第三次出现时，和棋。
- **双方同意**：双方一致同意和棋时，和棋。

---

## 6 特殊规则汇总

- 翻越：推进子可以进行以实线相邻的翻越子为支点，越过翻越子到其背后结点的特殊移动。
- 蹩马腿：当马腿结点不存在或被占据时，该马步不能走。
- 后手平衡规则：左方推进子达标时，若右方推进子可一步合规达标，则右方获胜。
- 达标无阻规则：推进子无视目标点上的对方棋子。
- 威胁子高度限制：威胁子不能进入禁区。

|---|---|:---|
| 结点 | Node | 棋盘上存在的位置，用整数坐标 `(c, r)` 表示 |
| 原点 | Origin | `(0, 0)` |
| 目标点 | Target point | `(3, 6)` |
| 左方起点 | Left starting point | 左方推进子初始位置 `(1, 0)` |
| 右方起点 | Right starting point | 右方推进子初始位置 `(5, 0)` |
| 禁外中轴顶 | Top of central axis outside forbidden zone | `(3, 4)` |
| 盘心 | Center | `(3, 3)`，棋盘几何中心结点 |
| 中轴底 | Bottom of central axis | `(3, 2)` |
| 棋盘中轴 | Central axis | 列 `c = 3` |
| 左方中轴 | Left side central axis | 列 `c = 1` |
| 右方中轴 | Right side central axis | 列 `c = 5` |
| 禁区 | Forbidden zone | 所有满足 `r ≥ 5` 的结点的集合 |
| 左肩 | Left shoulder | 所有满足 `c ≤ 2, r = 4` 的结点的集合|
| 右肩 | Right shoulder | 所有满足 `c ≥ 4, r = 4` 的结点的集合 |
| 左肋 | Left flank | 所有满足 `c ≤ 2, r = 3` 的结点的集合 |
| 右肋 | Right flank | 所有满足 `c ≥ 4, r = 3` 的结点的集合 |
| 左髋 | Left hip | 所有满足 `c ≤ 2, r = 2` 的结点的集合 |
| 右髋 | Right hip | 所有满足 `c ≥ 4, r = 2` 的结点的集合 |
| 实线相邻 | Solid-line adjacent | 由一条实线直接相连 |
| 虚线相邻 | Dashed-line adjacent | 由一条虚线直接相连 |

1. **棋子**

| 中文 | 英文 | 定义 |
|---|---|:---|
| 推进子 | Advancer | 负责达标和需要受到保护的棋子 |
| 翻越子 | Vaulter | 辅助推进子达标，并反制对方威胁子的棋子 |
| 阻碍子 | Blocker | 限制路线的棋子 |
| 威胁子 | Threat | 反制对方推进子的棋子 |
| 位置 | Position | 所在结点的坐标 |
| 布局 | Layout | 一方所有棋子及其所在结点的坐标 |
| 初始布局 | Initial layout | 开局时的布局 |
| 控制 | Control | 某棋子按其移动方式能够到达并吃子的结点，称为该棋子控制的结点 |
| 走 | Move | 一次合规移动，移动到空结点并占据该结点 |
| 吃 | Capture | 一次合规移动，移动到有对方棋子的结点，移除该对方棋子并占据该结点 |
| 移动方式 | Movement type | 第 3.2 节列出的合规移动形式 |
| 实步 | Solid step | 沿一条实线移动到相邻结点的一步移动 |
| 虚步 | Dashed step | 沿一条虚线移动到相邻结点的一步移动 |
| 翻越 | Vault | 推进子以实线相邻的翻越子为支点，越过翻越子到其背后结点的特殊移动 |
| 背后结点 | Node behind | 推进子所在结点与实线相邻的翻越子所在结点，沿延长线方向再经过一实线到达的结点，称为该翻越子相对于推进子的背后结点 |
| 马步 | Knight move | 翻越子从 `(c, r)` 移动到 `(c ± 1, r ± 2)` 或 `(c ± 2, r ± 1)` 的移动方式，受蹩马腿规则限制 |
| 蹩马腿 | Leg block | 马步对应的马腿结点不存在或被占据，使该马步不能走 |
| 马腿结点 | Leg node | 从 `(c, r)` 到 `(c ± 1, r ± 2)` 时，马腿结点为 `(c, r ± 1)`；到 `(c ± 2, r ± 1)` 时，马腿结点为 `(c ± 1, r)` |
| 车步 | Rook move | 威胁子沿水平或垂直方向移动，路径上所有结点必须存在且为空 |

1. **规则**

| 中文 | 英文 | 定义 |
|---|---|:---|
| 胜 | Win | 达成第 5.1 节任一胜利条件 |

| 行棋 | Play | 选择一个己方棋子，进行一次合规的移动 |
| 先手 | First player | 左方 |
| 后手 | Second player | 右方 |

| 达标 | Reach target | 棋子移动到 `(3, 6)` |
| 推进子达标 | Advancer reaches target | 推进子移动到 `(3, 6)` |
